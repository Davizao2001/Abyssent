# Abyssent — Site Oficial

Site institucional e vitrine de marca da **Abyssent Cloth**, marca brasileira de streetwear especializada em calças jeans baggy customizadas à mão.

## Sobre o projeto

Site single-page cinematográfico com storytelling em 6 capítulos, animações controladas por scroll, carrossel de lookbook, seção de produtos do DROP 01 e integração com Spotify.

## Tecnologias

- HTML5 · CSS3 · JavaScript ES6+
- GSAP + ScrollTrigger
- Lenis (scroll suave)
- SplitType (animações de texto)

## Como usar

Abra o arquivo `index.html` diretamente no navegador. O site é 100% autocontido — vídeos e imagens estão embutidos.
